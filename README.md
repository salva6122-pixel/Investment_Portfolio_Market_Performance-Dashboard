📊 Dashboard Overview

The dashboard provides an interactive view of portfolio data across different sectors and portfolio strategies.

Key Metrics
Total Portfolio Value – Overall value of the portfolio.
Total Daily P&L – Daily profit and loss.
Average Return – Average portfolio return.
Total Holdings – Number of holdings/assets tracked.
Average Risk Score – Overall portfolio risk indicator.
Buy Recommendations – Number of assets receiving a buy recommendation.
