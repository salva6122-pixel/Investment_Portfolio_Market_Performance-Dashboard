📊 Overview

The Portfolio Performance & Risk Dashboard is an interactive financial analytics dashboard designed to provide a consolidated view of portfolio performance, asset allocation, risk, and investment actions.

The dashboard allows users to analyze portfolio data across different sectors and portfolio strategies, including Aggressive, Balanced, Growth, Income, and Retirement.

✨ Key Features
Portfolio Filters
Sector: Automotive, Bonds, Commodities, Consumer, Consumer Staples, Digital Assets, Financials, Semiconductors, Technology
Portfolio: Aggressive, Balanced, Growth, Income, Retirement
Interactive filtering enables users to analyze specific portions of the portfolio.
KPI Cards

The dashboard displays key portfolio metrics:

KPI	Description
Total Portfolio Value	Overall value of the portfolio
Total Daily P&L	Daily profit/loss generated by the portfolio
Average Return	Average portfolio return
Total Holdings	Number/value of portfolio holdings
Average Risk Score	Average risk level associated with holdings
Buy Recommendation	Number of holdings receiving a buy recommendation
Visualizations

The dashboard contains several analytical charts:

Portfolio Value by Sector – compares portfolio value across sectors.
Portfolio Allocation by Asset Class – displays allocation between Crypto, Equity, and ETF assets.
Daily P&L Ticker – compares daily profit/loss across individual securities.
Return by Ticker – shows returns for individual securities.
Action Distribution – visualizes Buy, Sell, and Hold recommendations.
Analyst Rating Distribution – compares analyst ratings across securities.
