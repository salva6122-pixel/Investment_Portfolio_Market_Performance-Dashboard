## 📌 Overview

The **Portfolio Performance & Risk Dashboard** brings important portfolio metrics and financial insights together in a single interactive dashboard.

Users can filter the dashboard by:

- **Sector**
- **Portfolio Type**
- **Asset Class**
- **Individual Tickers**

The dashboard is designed to make portfolio analysis easier through interactive KPIs and visualizations.

---

## ✨ Features

### 📈 Key Performance Indicators

- 💰 Total Portfolio Value
- 📊 Total Daily P&L
- 📈 Average Return
- 🏦 Total Holdings
- ⚠️ Average Risk Score
- ⭐ Buy Recommendations

### 📊 Visualizations

- **Portfolio Value by Sector**
- **Portfolio Allocation by Asset Class**
- **Daily P&L by Ticker**
- **Return by Ticker**
- **Buy / Sell / Hold Distribution**
- **Analyst Rating Distribution**

### 🔎 Interactive Filters

The dashboard includes filters for:

**Sectors**
- Automotive
- Bonds
- Commodities
- Consumer
- Consumer Staples
- Digital Assets
- Financials
- Semiconductors
- Technology

**Portfolio Types**
- Aggressive
- Balanced
- Growth
- Income
- Retirement
