Purpose: Portfolio Performance & Risk Dashboard for monitoring investment performance and risk.
Filters: Sector and portfolio-type filters allow users to view specific segments.
Key KPIs: Total Portfolio Value, Daily P&L, Average Return, Total Holdings, Average Risk Score, and Buy Recommendations.
Portfolio Value by Sector: Shows the distribution of portfolio value across sectors.
Asset Allocation: Displays portfolio allocation among Crypto, Equity, and ETF asset classes.
Daily P&L Ticker: Compares daily profit/loss across individual securities.
Return by Ticker: Visualizes the return generated by each security.
Action Distribution: Shows the number of Buy, Sell, and Hold recommendations.
Analyst Rating Distribution: Compares analyst ratings across the selected securities.
Use: The dashboard can support portfolio monitoring, risk assessment, asset allocation analysis, and investment-action tracking.
